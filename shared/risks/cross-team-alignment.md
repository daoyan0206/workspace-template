# 跨团队对齐风险登记

> **只追加,不修改已有条目**。
> 当工作区内角色在产出过程中发现 out-of-scope 模块的缺失会导致【用户体验断层】或【系统逻辑断层】时,追加一条风险记录。

## 模板

```
## RISK-NNN: <风险标题>
- **登记日期**: YYYY-MM-DD
- **登记人**: <角色名>
- **来源**: <在哪个产出/讨论中发现>
- **风险描述**: <一段话说清楚断层在哪>
- **断层类型**: 用户体验断层 / 系统逻辑断层
- **影响范围**: <Demo / Beta / 正式版>
- **阻塞级别**: 🔴 阻塞 / 🟡 影响 / 🔵 提示
- **责任方**: <预期由哪个外部团队负责>
- **建议动作**: <对齐内容 / 时间窗 / 联系人>
- **状态**: Open / In-Discussion / Resolved
```
